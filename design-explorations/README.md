# FarmQuest — Design Explorations

Three intentionally differentiated landing-page directions for FarmQuest. Each is a single
self-contained HTML file (open directly in a browser). Goal: pick one direction, then iterate.

## Option 1 — Night Trail (`option-1-night-trail.html`)
**Indie adventure game.** Dark forest-green palette, glowing gold accents, chunky display type
(Bungee), dashed quest trail, phone mock showing a live chapter with choices.
- Speaks to: **students first** — feels like a real game, zero "edtech" smell.
- Risk: darkest and boldest of the three; teachers/parents may read it as "entertainment."

## Option 2 — Field Journal (`option-2-field-journal.html`)
**Warm storybook editorial.** Cream paper texture, serif typography (Fraunces), handwritten
annotations (Caveat), rotated pinned postcards, a circular "Teacher Reviewed" stamp, a real
story excerpt styled like a printed page.
- Speaks to: **parents and educators first** — literary, trustworthy, charming.
- Risk: reads slightly young/quaint for high schoolers; least "techy."

## Option 3 — Clear Sky (`option-3-clear-sky.html`)
**Minimal modern edtech SaaS.** White space, Inter, single green accent, stats bar,
teacher-dashboard mock with approval states, benefit checklists.
- Speaks to: **the adult buyer** (teachers, districts, farm partners) — credible, product-forward.
- Risk: most conventional; carries the least story/adventure feeling.

All three share the same content skeleton (hero → 3-phase journey → teacher trust →
audience → pilot CTA) so the comparison isolates *visual language*, not information design.
Webfonts load from Google Fonts with system fallbacks; everything works offline too.
